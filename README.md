# Project Documentation

This repository contains setup and usage instructions for different modules of the project.  
Please refer to the appropriate README files below depending on the functionality you want to run.

## Available Guides

- **README_autoware_setup.md**  
  Use this guide for setting up and running **Autoware**.

- **waypoint_and_slam.md**  
  Use this guide for running **SLAM** or **Waypoint Following** modules.

- **smdm.md**  
  Use this guide for running the **SMDM**.
  
- **README_Sensor_Kit_Setup.md**  
  Use this guide if you are **setting up your own sensor kit** (e.g., adding new sensors or replacing existing ones).  
  If not, please use the **default sensor kit configuration provided in this repository**.
